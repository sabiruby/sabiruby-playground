# 2026-10-19 SabiRuby 0.8.0 から建てる

SabiRuby の `docs/plans/release-0.8-plan.md` の R5（下流のバージョン上げ）。著者の指示（2026-10-19）は「R5 の下流のバージョン上げ、進めて」。
着手時の先頭は main の `9108607`（`SABIRUBY_REF` は `4d3036a` = v0.7.0）。

## 変えたもの

- `.github/workflows/pages.yml` の `SABIRUBY_REF` を `7f74cd1`（tag `v0.8.0`: `sabiruby` 0.8.0、`sabiruby-compiler` 0.5.0）に。コメントに前の 2 つ（v0.7.0、v0.6.1）を残した。
- `wasm/Cargo.lock`: `tools/build.sh` が path の依存を読み直して `sabiruby 0.7.0 -> 0.8.0`、`sabiruby-compiler 0.4.0 -> 0.5.0` に書き換えたもの（0.7.0 の commit `9108607` と同じ形）。
- README の「Pinned versions」の SabiRuby の行。**v0.6.1 のまま**で、0.7.0 の commit が直し忘れていた。v0.8.0 に。mruby compiler の行に
  「`mruby-compiler` は 4.1.0-rc2 でも同じ」を足した（SabiRuby `compiler/README.md` の 24〜25 行。0.8.0 で基準が rc2 になったため）。
  モジュールの大きさの行に v0.8.0 の数を 1 文足した（下）。

コードは 1 行も変えていない。SabiRuby の R2（SabiRuby `docs/worklog/2026-10-19-release-0.8.md` の 8 節）が写しで同じ確かめを取っており、
`wasm/src/lib.rs` が呼ぶもの（`Vm::next_line` など）は 0.8 でも変わっていない。

## 確かめ

隣の `../sabiruby` は main の `f06a23a`（`v0.8.0` = `7f74cd1` の 1 つ後。違いは docs の 2 ファイルだけ、`git diff --stat 7f74cd1 f06a23a`）。
ソースは tag と同じなので、そのまま path で読んで建てた。

```
$ PATH=~/.local/binaryen-version_132/bin:$PATH tools/build.sh
    Updating sabiruby v0.7.0 (…/sabiruby) -> v0.8.0
    Updating sabiruby-compiler v0.4.0 (…/sabiruby/compiler) -> v0.5.0
web/sabiruby.wasm: 2469338 bytes (853442 gzipped)
$ npm test                 18/18 fixtures match the reference output、26/26 checks
$ npm run test:browser     22 行 ok（"no errors in the console" を含む）、all passed
```

1 度目は `wasm-opt` が PATH に無く（`wasm-opt not found: copying the unoptimised module`、2,766,036 bytes）、binaryen 132 を PATH に足して建て直した。
README の数はその 2 度目（CI と同じ wasi-sdk 34・binaryen 132）。README の他の数は公開のページから測った「Pages が配る gzip」なので、
こちらは `gzip -9` と書き分けた。
